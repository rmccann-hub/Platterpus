## D. Log-format delta

**One line changes, and it has never appeared in an archived rip.**

### D1 — `Cache probe:`

`-x` executed on a real drive on 2026-08-10, for the first time in this
project's existence. Every disc-image fixture refuses the probe by design, so
nothing before this had ever run it. It printed:

```
Cache probe:    32 sectors measured (73.5 KiB, uncached read 364.3 ms)
```

Two defects in one line, both fixed at `1f00653`:

- The search **doubles**, so it can only ever return a power of two. A hit at
  32 and a miss at 64 establishes that the cache holds at least 32 sectors and
  fewer than 64 — it does not measure 32. "measured" claimed a precision the
  method cannot deliver, which is the `Cache defeat:` → `Cache model:` lesson
  one level in.
- The loop stops for **four** reasons — a genuine cache miss, a failed read, a
  read it could not time, or running out of room — and all four printed that
  same sentence. "The cache ran out at 64 sectors" and "the read at 64 sectors
  failed" are different claims about the drive.

The nine wordings it can now emit are pinned by `tests/cacheprobe.c` and
listed in `PROVIDER-CONTRACT.md` P2. The shape you will see on the rig is:

```
Cache probe:    32 to 63 sectors (73.5 to 144.7 KiB, uncached read 364.3 ms)
```

**No other log line changed.** Said out loud rather than left to inference.

### D2 — the contract grew by 10 fatal messages, and the program did not

`PROVIDER-CONTRACT.md` P5 never contained genopt's own diagnostics — including

```
Unable to parse command line argument: %s
```

the message that once read to a consumer as *"cyanrip is not installed"*, and
the reason this fork restored `-V`. The anchor has always claimed to cover
`src/*.h`, and `genopt.h` has always been in `src/`; the scan simply had no
pattern for `GEN_OPT_LOG`. **These messages were always emitted. Only the
document was incomplete.** If your parser matches on our fatal inventory, it
now has ten rows it did not have, and they describe behaviour that has been
there all along.
